# 豊臣大坂城、夜明けから日没までに立ち上がる

豊臣秀吉の大坂城（1580年代）が、夜明けから日没までの1日のタイムラプスで建ち上がっていく30秒（900フレーム・30fps）の3Dアニメーションを、Blenderで作るための設計とPythonスクリプトです。

外部アセットがなくても、スクリプトを1回実行すればシーン全体（地形・堀・石垣・本丸・天守・作業員・光・カメラ・テロップ）ができます。後から高品質な城モデル・人物・瓦テクスチャ・空のHDRIへ差し替えやすい構造にしてあります。

| ファイル | 内容 |
|---|---|
| `toyotomi_osaka_castle_timelapse.py` | Blenderのテキストエディタに貼り付けて実行するスクリプト（約2,500行・コメント多め） |
| `README.md` | この設計書 |

## すぐに使う

1. Blender 4.2以降を起動し、上部タブの **Scripting** を開く
2. テキストエディタの［開く］で `toyotomi_osaka_castle_timelapse.py` を選ぶ（または新規テキストに全文を貼り付け）
3. 先頭の `CFG`（ユーザー設定）を必要に応じて書き換える
4. ▶（スクリプト実行、Alt+P）。数秒でシーンが生成される
5. 3Dビューでテンキー0（カメラ視点）→ Spaceで再生
6. 書き出す前に `.blend` を保存し（出力先 `//render/` は .blend からの相対パス）、`CFG["QUALITY"] = "FINAL"` にして再実行 → Ctrl+F12

PNG連番をMP4にまとめる例：

```sh
ffmpeg -framerate 30 -i render/toyotomi_osaka_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 toyotomi_osaka.mp4
```

再実行すると、前回このスクリプトが作ったもの（名前が `TS_` で始まるもの）だけを消して作り直します。自分で追加したオブジェクトは消えません。

## 1. 全体設計

### 考え方

- **1本の長回し。** 何年もかかった築城を、1日の光の変化に重ねて30秒に圧縮します。時間の経過は、太陽の移動・空の色・影の向き・作業員の動き・資材の増減・建物の出現で見せます。
- **手続き生成＋スケジューラー。** 建物の部材はすべてPythonで生成し、各オブジェクトに「いつ・どう現れるか」をカスタムプロパティ（`b_start` など）として書き込みます。最後に `apply_build()` がそれをキーフレームに変換します。
  - 演出を直すときはプロパティ（数字）を変えるだけで済みます。
  - 差し替えたモデルにも同じプロパティを付ければ、同じように建ち上がります。
- **アセットはインスタンス配置。** 作業員・牛車・町家・松・鯱は、非表示のアセット用コレクションの中身をインスタンスで並べています。中身を入れ替えれば、シーン中のすべてが置き換わります。
- **黒と金を主役に。** 周囲（石垣の灰色、漆喰の白、草地の緑、空の青）は控えめな色にし、天守の黒漆と金箔瓦のコントラストが最も強く見えるように色を組んでいます。

### 配置（単位m、+X=東、+Y=北）

```
                              北 (+Y)
   ┌─────────────────── 堀の外形 280×250（水面 -2.2m / 堀底 -6m）───────────────┐
   │      ┌──────────────── 本丸（下段）180×150・上面 +10m ────────────────┐      │
   │      │ 櫓                                                       櫓 │      │
   │      │        御殿B    ┌──── 詰ノ丸（上段）90×75・+16m ────┐       │      │
   │ 西 │ 櫓 │                │ 櫓     御殿C       ■天守台・天守 │ 櫓 │ 東 │
   │      │                 │ 櫓                        櫓 │       │      │
   │      │   御殿A          └───────────────────────┘       │      │
   │      │ 櫓              幟・千成瓢箪   【大手の櫓門】            櫓 │      │
   │      └──────────────────────────────┼─────────────────────┘      │
   └──────────────────────────────────┼ 木橋 ──────────────────────────┘
                     石材・丸太置き場   高麗門   牛車の街道（南へ）
   西の城下町（町家が夕方に増える）
```

- 天守は史実に倣い、本丸の北東寄り（詰ノ丸）に置いています（`L["TENSHU_C"]` で変更可）。
- 天守は外観五重で、天守台と鯱を含めた高さは地面から約66mです。

## 3. アニメーション設計

### タイムライン（30fps・900フレーム）

| フレーム | 時刻 | 起きること |
|---|---|---|
| 1〜150 | 夜明け | 朝霧の更地と台地。木杭が打たれ、縄が張られる（12〜130）。石材が運び込まれて増える。作業員が現れ動き始める。牛車が街道を往復。タイトル（8〜112） |
| 150〜300 | 朝 | 堀を4辺順に掘る（フタが沈む：150〜245）。本丸の石垣が4面それぞれ下から積み上がる（160〜298）。外側の石垣（175〜285）。水が満ちる（235〜300）。詰ノ丸の石垣（250〜330）。クレーンが旋回して石を吊る。石材の山が減る |
| 300〜500 | 昼 | 木橋（300〜332）、高麗門、大手の櫓門（335〜375）。塀が周囲に伸びる（340〜470）。櫓9基（360〜490）。本丸御殿3棟（420〜495）。幟が立つ（470〜495）。丸太が減り始める |
| 500〜750 | 午後 | 天守台を積む（500〜536）。天守を一重ずつ（520から40フレームごと）：床→足場→柱→梁→黒漆の壁→窓・金の帯→野地→瓦→千鳥破風→金の軒先・鬼瓦（きらめき）。最上重は金の障壁画と高欄。大棟（722）、金の鯱（728〜736）。足場を上から外す（736〜758）。城下町が建ち始める（590〜） |
| 750〜900 | 夕方 | 完成。夕日で金が自ら輝き（GoldGlow）、鯱・鬼瓦・千成瓢箪がきらめく。堀の水面に城が映る。町家が増え続ける（〜860）。カメラが引いてワイドに。締めのテロップ（826〜） |

### 出現のしかた（`b_mode`）

スケール・透明度・位置の各アニメーションを組み合わせて、「地面から立ち上がる」ように見せます。

| モード | 動き | 使っている所 |
|---|---|---|
| `reveal` | マテリアルのマスクで、下から上へ積み上がる（伸び縮みしない） | 石垣（石1個ずつ）、天守の壁と瓦、櫓・御殿の壁 |
| `grow` | 底面（または端）を基準に、指定の軸方向へ伸びる | 柱、塀、縄、足場、橋 |
| `drop` | 上から降りながらフェードイン | 屋根、野地 |
| `rise` | 下からせり上がりながらフェードイン | 水面、床、門 |
| `pop` | 弾むように現れる（1.12倍まで行き過ぎて戻る） | 金の装飾、窓、資材、町家、幟 |
| `fade` | 透明から不透明へ | 町の通り |

消え方（`b_end_mode`）は、`shrink`（縮んで消える：資材・足場）・`sink`（沈む：掘削前の地面）・`fade`・`none` の4種類です。

石垣の `reveal` では、ボロノイの各セル（石1個）の中心の高さで判定します。そのため、石が1個ずつ置かれていくように積み上がります。セルごとに少し乱数を足しているので、同じ高さの石も一斉には現れません。

### タイムラプス感の作り方

- **作業員：** 時間帯ごとの持ち場（夜明けは南の置き場と台地、朝は堀の周り、昼は本丸、午後は詰ノ丸と天守の足場、夕方は城下）に現れます。5〜14フレームで小移動しては立ち止まり、30〜80フレームで消えて別の場所に現れます（タイムラプス写真で人がちらつく感じ）。
- **資材：** 石材は夜明けに増えて朝に減り、丸太は昼から午後にかけて減ります。
- **雲と影：** 雲が速く流れ、地面を雲の影が走ります。
- **光：** 太陽の方位が68°から268°まで動き、影が大きく回ります。

## 4. マテリアル設計

建物用のマテリアルには、すべて共通の **建設マスク**（ノードグループ `TS_BuildMask`）を組み込んでいます。マスクはオブジェクトのカスタムプロパティをAttributeノード（Object）で読みます。

| プロパティ | 意味 |
|---|---|
| `b_transp` | 0＝不透明、1＝透明（フェード） |
| `b_reveal_on` / `b_reveal_z` | 1のとき、ワールド高さ `b_reveal_z` より上を隠す（積み上がり） |
| `b_glint_v` | 金箔マテリアルの発光パルス（きらめき） |
| `band_z` | 漆喰マテリアルで、この高さより下を黒い腰板にする |

| マテリアル | 見た目 | 作り方 |
|---|---|---|
| `TS_KuroUrushi` 黒漆 | ほぼ黒（0.01）、クリアコートでつや | ワールドZの正弦波で下見板（横板）の凹凸。天守の壁・妻・門扉 |
| `TS_Kinpaku` 金箔 | 金属1.0、粗さ0.12〜0.30のムラ | 粗さのムラはボロノイ。発光＝`b_glint_v`×14＋`GoldGlow`（夕景用、キーで変化） |
| `TS_Kawara` 瓦（いぶし瓦） | 暗い青灰、金属0.35 | 面の向き（法線）で丸瓦の列方向を切り替える正弦波バンプ＋段のバンプ |
| `TS_Ishigaki` 石垣（野面積み） | 灰〜茶の不揃いな石と暗い目地 | 横長に引き伸ばしたボロノイで石と目地を作り、色を石ごとにばらつかせる。マスクの高さには石の中心を使う |
| `TS_Shikkui` 漆喰＋腰板 | 白壁と黒い腰板 | オブジェクト座標のZが `band_z` 未満なら黒（塀・櫓・御殿・町家） |
| `TS_Ground` 地面 | 中心は土、外は草地 | 原点からの距離＋ノイズで混ぜる |
| `TS_Water` 堀の水 | 暗い青緑、粗さ0.04 | 4Dノイズの時間軸を動かして、さざ波のバンプ |
| `TS_Hiwada` 檜皮葺 | 赤茶 | 御殿の屋根 |
| `TS_Mountain` 遠山 | 空の色に溶ける | 地平線の色（`Haze`、キーで変化）の発光を6割混ぜる（空気遠近法） |
| `TS_Fog` 朝霧 | 地表ほど濃いボリューム | 高さで減衰させた密度を `FogDensity` のキーで薄くしていく |
| その他 | 白木・古材・縄・野地・板葺・土・砂利・道・松・肌・藍・茶・白布・陣笠・牛・窓 | 単色＋ノイズのムラ |

**テクスチャの差し替え：** `CFG["TEXTURES"]` に画像のパスを書くと、`kawara`・`ishigaki`・`kuro`・`shikkui`・`wood`・`ground` のベースカラーがボックス投影の画像に置き換わります。

## 5. ライティング設計

| 要素 | 内容 |
|---|---|
| 太陽 | Sunライト1灯。`SUN_KEYS` で方位・高度・色・強さ・光源の角度（影の柔らかさ）をキー |
| 空 | グラデーションのワールド（天頂色／太陽側の地平線／反対側の地平線／太陽のにじみ）。`SKY_KEYS` でキー。太陽方向は太陽ライトと同期 |
| 露出 | `EXPOSURE_KEYS`。暗い朝夕は明るく、昼は絞る（実際のタイムラプス撮影の自動露出と同じ考え方） |
| 朝霧 | 地表ほど濃いボリューム。夜明けに濃く、昼に向けて薄くなる。夕方はわずかに戻す |
| 金の輝き | 夕方（745〜900）に金箔が自ら少し発光。天守の各重の完成時、鯱・千成瓢箪にきらめき（星形の光＋発光パルス） |
| グレア | コンポジターのブルームで、金のハイライトをにじませる |

| 時刻 | フレーム | 太陽（方位/高度） | 色の狙い |
|---|---|---|---|
| 夜明け | 1〜60 | 68°/−1° → 74°/4° | 薄い青と薄橙、地平線がピンク、霧が濃い |
| 朝 | 150 | 92°/16° | 青空と暖かい横からの光、長い影 |
| 昼 | 300〜520 | 125°/42° → 175°/63° → 215°/52° | 明るい白い光、短い影 |
| 午後 | 650 | 245°/30° | 少し黄色く、影が東へ伸びる |
| 夕方 | 750〜900 | 258°/15° → 268°/2.5° | 金色から深いオレンジ。城の西面が金色に照らされ、背景の東の空は紫 |

最後のワイドショットでは、カメラを西南西に置いて太陽を背にしています。夕日を正面から受けた黒と金の天守が、紫がかった東の空の前に浮かぶ構図です。

## 6. カメラ設計

カメラ1台を `CAM_KEYS`（注視点・方位・距離・高さ・焦点距離）で動かします。キーの間はなめらかな曲線で補間し、3フレームごとにキーを打っています。方位で指定しているので、注視点の周りを回り込む動きが自然に作れます。

| フレーム | ショット | 意図 |
|---|---|---|
| 1〜100 | 地面すれすれ（高さ1.8m、24mm）。南の置き場から北の台地を見る | 霧の中の杭・縄・資材・作業員・牛車。前景に人が入る |
| 100〜240 | ゆっくり後退しながら上昇（11m → 34m） | 堀が掘られ、石垣が立ち上がる |
| 240〜410 | 南東から大きく上昇し俯瞰（118m） | 本丸・門・塀・櫓の全体像 |
| 410〜570 | 天守台へ寄っていく（30m、32mm） | 天守台の石積みと一重目 |
| 570〜720 | 天守の周りを南→南西へ回り込みながら見上げる（高さ20〜38m） | 下から上へ組み上がる天守を見上げる迫力 |
| 720〜835 | 西へ回り、堀の水面越しの低めの視点へ（22m） | 水面に映る天守、夕日の金色 |
| 835〜900 | 大きく引いてワイド（385m、95m） | 城全体・石垣・堀・西の城下町のはじまり |

`CFG["USE_DOF"] = True` で被写界深度を付けられます（既定は、テロップもぼけるのでオフ）。

### 構成

| 章 | 内容 |
|---|---|
| 0 | ユーザー設定 `CFG`、テロップ文言 `TITLES`、タイムライン `PH`、配置 `L`、天守 `TENSHU_LEVELS`、光とカメラのキー表 |
| 1 | コレクション・削除・メッシュ生成（箱・円柱・角材・反り屋根・石垣の断面・切妻）・キーフレームの補助 |
| 2 | マテリアル（建設マスク付き） |
| 3 | 建設アニメーション・スケジューラー（`sched()` → `apply_build()`） |
| 4 | 差し替え用アセット |
| 5〜10 | 環境・縄張り・石垣・本丸・天守・普請場・人と町 |
| 11 | カメラ・きらめき・テロップ |
| 12 | レンダー設定・コンポジター |
| 13 | `main()` |

### 主な設定（`CFG`）

| キー | 既定 | 説明 |
|---|---|---|
| `ENGINE` | `"EEVEE"` | `"CYCLES"` にすると高品質（遅い） |
| `QUALITY` | `"PREVIEW"` | `"FINAL"` で解像度100%・高サンプル |
| `ASPECT` | `"16:9"` | `"9:16"` でショート動画・リール用の縦型（1080×1920） |
| `WORKERS` / `TOWN_HOUSES` / `TREES` / `OXCARTS` | 160 / 130 / 70 / 6 | 減らすと軽くなる |
| `USE_FOG` / `USE_CLOUDS` / `USE_TITLES` / `USE_GLARE` / `USE_DOF` | 霧・雲・テロップ・グレアはオン、DOFはオフ | 演出のオン・オフ |
| `FONT_PATH` | 自動検出 | 游明朝・MS明朝・ヒラギノ明朝などを順に探す。見つからなければテロップは省略 |
| `HDRI_PATH` | 空 | 指定すると空をHDRIに置き換え（太陽ライトは残る） |
| `TEXTURES` | 空 | 瓦・石垣・黒漆・漆喰・木・地面の画像 |
| `OUTPUT_VIDEO` | `False` | `True` でMP4を直接書き出し。既定はPNG連番（途中から再開できる） |
| `MODE` | `"FULL"` | `"ANIM_ONLY"` で建設アニメーションだけ作り直す（差し替え後に使う） |

### 差し替えのしかた

- **作業員・牛車・町家・松・鯱：** `TS_99_ASSETS_差し替え用` の中の `TS_ASSET_xxx` コレクションの中身を、自分のモデルに入れ替えるだけです（原点＝足元、正面＝+Y、作業員は身長約1.7m）。全インスタンスが自動で置き換わります。
- **天守・櫓などの建物：**
  1. 高品質モデルを読み込み、生成された `TS_04_天守` を非表示にする
  2. 自分のモデルの部品にカスタムプロパティを付ける。`b_start`（開始フレーム）・`b_dur`（長さ）・`b_mode`（`reveal` など）
     - 手作業が大変なら、スクリプトの関数 `auto_schedule_by_height(オブジェクト一覧, 520, 725)` を使うと、低い部品から順に自動で割り振れる
  3. 部品に `TS_` のマテリアル（`TS_KuroUrushi`・`TS_Kinpaku`・`TS_Kawara` など）を割り当てると、`reveal` やきらめきがそのまま効く。自前のマテリアルを使う場合は、ノードグループ `TS_BuildMask` を通して透明と混ぜる
  4. `CFG["MODE"] = "ANIM_ONLY"` にして再実行する（建物は作り直さず、アニメーションだけ付け直す）
- **空：** `CFG["HDRI_PATH"]` に夕景・朝焼けのHDRIを指定します。時刻で空を変えたい場合は、`build_world()` の環境テクスチャを2枚にして混ぜます。

## 8. 追加で手作業調整すべきポイント

1. **天守の作り込み。** 唐破風、華頭窓、入母屋の破風、廻縁の細部、最上重の金の障壁画（虎・鶴など）は簡略化しています。ヒーローショット（570〜760）で大きく映るので、ここに手を入れるのが最も効果的です。
2. **屋根の反り。** `bm_jroof()` の `curve`（反りの強さ）と `lift`（隅の反り上がり）を重ごとに調整すると、ぐっと日本の城らしくなります。
3. **石垣の立体感。** 今はバンプだけです。Cyclesなら、アダプティブサブディビジョン＋ディスプレイスメントで石を浮き出させるか、石を個別のメッシュにすると重量感が増します。
4. **作業員。** 今は簡易な人型が滑るように動きます。リグ付きの人物（歩き・担ぎのアニメーション付き）に `ASSET_worker_*` の中身を差し替え、モーションブラーを入れると、タイムラプスの人のちらつきがよりリアルになります。
5. **牛車の車輪。** 回転していません。車輪をドライバーで移動距離に連動させてください。
6. **瓦と漆のテクスチャ。** 近いショット（650〜760）では、`CFG["TEXTURES"]` に実写の瓦・木目を入れると質感が上がります。
7. **雲。** 今は丸いメッシュです。ボリュームの雲やHDRIの空にすると、夕景がよりドラマチックになります。
8. **霧。** Cyclesではボリュームが重いので、プレビューでは `USE_FOG = False` にするか、EEVEEで作業してください。EEVEEでは `volumetric_tile_size` を小さくすると霧がなめらかになります。
9. **カメラ。** `CAM_KEYS` を書き換えると構図をまとめて調整できます。縦型（9:16）は横の画角が狭くなるので、距離（4列目）を1.2〜1.4倍にして確認してください。わずかな手持ち感が欲しければ、カメラの親にノイズモディファイアを付けたEmptyを入れます。
10. **テロップ。** 明朝体を `FONT_PATH` で指定するのがおすすめです。凝った字幕は、編集ソフト（DaVinci Resolve・Premiereなど）で入れてもかまいません（`USE_TITLES = False`）。
11. **色の仕上げ。** AgXの「Medium High Contrast」を基本にしています。仕上げのグレーディング（黒を締め、金の彩度を少し上げる）を編集ソフトで行うと、SNS向けに映えます。
12. **音。** 槌音、石を引く掛け声、太鼓、夕方の鐘などの効果音とBGMを付けると、30秒の満足感が大きく変わります。
13. **時代考証。** 下の「史実について」のとおり、豊臣期の大坂城の細部には諸説あります。展示や教育用途なら、専門家の確認をおすすめします。

## 史実について（どこまで史実で、どこから演出か）

- **築城：** 天正11年（1583）に築城開始。天守は天正13年（1585）頃に完成したとされます。本丸の外側（二の丸・三の丸・惣構え）の工事は、その後も長く続きました。
- **天守の姿：** 「大坂夏の陣図屏風」（大阪城天守閣蔵）などの絵画資料と、出土した金箔瓦から推定されている姿を参考にしました。黒漆塗りの壁、金箔瓦、金の飾り、外観五重です。内部の階数や細部の意匠には諸説あり、この映像は推定を元にした「豊臣大坂城らしさ」の表現です。
- **天守の位置：** 本丸の北東寄りにあったとされるため、詰ノ丸の北東に置いています。
- **本丸：** 上段（詰ノ丸）と下段の二段構えを簡略化して表現しています。
- **石垣：** 豊臣期の石垣は、自然石を積む野面積みとされています。現在見られる大きく整った石垣は、徳川期に築き直されたものです。
- **今の大阪城との違い：** 現在の天守（1931年に復興）は、豊臣期と徳川期の意匠を合わせたものです。徳川期の天守は白壁でした。この映像は、それとは違う「黒と金」の豊臣期の姿を描いています。
- **規模：** 実際の豊臣大坂城は、三の丸・惣構えまで含めると、はるかに広大でした。映像では本丸周辺に絞り、縮尺も簡略化しています。
- **演出として加えたもの：** 千成瓢箪（秀吉の馬印として知られる）、幟の色、本丸御殿の檜皮葺の屋根、城下町の配置（のちの船場・上町を意識）、1日に圧縮した工程の順番。

## 動作確認

- Blender 4.2.23 LTS・4.5.15 LTS・5.2.3 LTSで、スクリプトの実行とCyclesのレンダリングを確認しました。Blender 5.2ではEEVEEのレンダリングも確認しています。
- 確認はGPUのない環境で行いました。そのため、レンダリング時間の実測値はCPUでのものだけです。GPUでの速度は未計測です。
- 生成にかかる時間は、約1,600オブジェクトで約1秒です（4.2・4.5では0.7〜0.8秒）。
